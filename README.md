# Kid Bike Racer

A fun 3D bike racing game for kids using Three.js.

## How to Play
1. Open index.html in a browser
2. Tap/click to make the bike jump
3. Avoid obstacles (green cones)
4. Collect yellow stars for points

## Features
- 3D graphics with Three.js
- Simple one-tap controls for kids
- Score tracking
- Colorful kid-friendly design

## Tech Stack
- Three.js (CDN)
- Vanilla JavaScript
- Single HTML file

## Run Locally
Simply open index.html in any modern browser.
